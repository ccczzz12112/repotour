## Git 三步（照抄即可）

**第一次，把仓库拉到本地**（找个你记得住的位置，比如桌面）：

    cd $env:USERPROFILE\Desktop
    git clone https://github.com/ccczzz12112/repotour.git
    cd repotour

**每天开工前，拉最新**：

    git pull

**改完自己的文件，提交推送**：

    git add submission handoff/evidence
    git commit -m "docs: 更新盲测报告与作品帖草稿"
    git push

> 只提交 `submission/` 和 `handoff/evidence/` 这两个目录，**别动 `backend/` `frontend/` `handoff/SPEC.md`**。
> 如果 `git push` 报错说落后了，先 `git pull` 再 `git push`。
> 不会用命令行就用 GitHub Desktop，或者直接在 GitHub 网页上传文件也行。
